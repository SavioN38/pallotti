## 4. Hosting & GitHub Pages Architecture

### 4.1 Repository & Branch Setup
- **GitHub Repository**: `https://github.com/SavioN38/pallotti`
- **Default Branch**: `main`
- **Live Output**: `https://savion38.github.io/pallotti/`

### 4.2 Dynamic Base URL Configuration
In [vite.config.ts](file:///c:/SavioN/Pallotti_Hill_Public_School_Website/vite.config.ts), Vite dynamically sets the base path depending on whether the application is running in local development mode or building for production:
```ts
export default defineConfig(({ command }) => {
  return {
    base: command === 'serve' ? '/' : '/pallotti/',
    // ...
  };
});
```
- During `npm run dev` (`command === 'serve'`), assets are resolved from `/`.
- During `npm run build`, assets and scripts are prefix-resolved to `/pallotti/`.

### 4.3 Static Client-Side Routing with `HashRouter`
GitHub Pages is a static file host that does not natively support server-side URL rewriting (fallback to `index.html`). To prevent `404 Not Found` errors when refreshing routes such as `/gallery/2025-26`, the app uses **`HashRouter`** in [main.tsx](file:///c:/SavioN/Pallotti_Hill_Public_School_Website/src/main.tsx):
- URL format: `https://savion38.github.io/pallotti/#/`
- Gallery URL format: `https://savion38.github.io/pallotti/#/gallery/2025-26`

### 4.4 GitHub Actions Workflow (`.github/workflows/static.yml`)
Pushes to the `main` branch trigger automated deployment:
1. Checks out repository (`actions/checkout@v4`).
2. Installs Node.js 20 with npm caching (`actions/setup-node@v4`).
3. Executes clean install `npm ci`.
4. Runs production build `npm run build`.
5. Uploads `dist/` directory as Pages artifact (`actions/upload-pages-artifact@v3`).
6. Deploys to GitHub Pages (`actions/deploy-pages@v5`).

## 5. Core Application Architecture & Pages

### 5.1 Root Application ([App.tsx](file:///c:/SavioN/Pallotti_Hill_Public_School_Website/src/App.tsx))
- **`<ScrollToTop />`**: Ensures any route transition immediately scrolls the window back to `(0, 0)`.
- **`<Routes>`**:
  - `/` &rarr; `<HomePage />`
  - `/gallery` &rarr; Redirects to default year (`/gallery/2025-26`)
  - `/gallery/:year` &rarr; `<GalleryPage />`
  - `*` (Catch-all) &rarr; Redirects to `/`
- **`<SchoolChatbot />`**: Globally persistent floating assistant mounted on all screens.

### 5.2 Home Page ([HomePage.tsx](file:///c:/SavioN/Pallotti_Hill_Public_School_Website/src/pages/HomePage.tsx))
The home page provides a rich narrative of Pallotti Hill Public School:
1. **Hero Section**:
   - **Dual-layer Media**: High-res poster fallback (`school.png`) overlaid with `<video>` (`campus_hero.mp4`).
   - **Randomized Seek Start**: Video starts randomly at one of 5 preset timestamps (`HERO_START_POINTS: 6s, 14s, 31s, 57s, 90s`) to showcase varied campus activities on each page load.
   - **Dual Gradient Scrims**: Ensuring typography contrast across varying light conditions.
   - **Primary CTAs**: "Begin your journey" (scrolls to admissions) and "Discover Pallotti Hill" (scrolls to about us).
2. **Key Metric Statistics**:
   - Animated count-up displays: 30+ Years of excellence, 850+ Students enrolled, 45+ Expert educators, 100% Board pass rate.
3. **The Pallotti Hill Difference**:
   - Narrative of institutional philosophy with 3 highlighted pillars: *Learning with purpose*, *A place to belong*, and *Room to become*.
4. **Campus Life Gallery Cards**:
   - Interactive editorial cards covering Academics, Sport, Arts, and Technology.
5. **Activities & Beyond**:
   - 4-quadrant feature cards: Visual Arts, Music & Performance, Sports & Wellness, Clubs & Societies.
6. **School Calendar / Events**:
   - Upcoming academic and cultural milestones (Parent orientation, Independence Day, Inter-house athletics, Annual art exhibition).
7. **Founder & Inspiration (St. Vincent Pallotti)**:
   - Dedicated biographical tribute to St. Vincent Pallotti and the Pallottine Fathers' international mission and presence in 46 countries.
8. **Meet The Team (Mentors)**:
   - Staff photograph showcasing the educator faculty and mentors.
9. **Alumni Speak**:
   - Interactive quote carousel featuring alumni reflections with navigation dots and smooth fade transitions.
10. **Admissions Invitation CTA**:
    - High-impact closing CTA banner with subtle Ken Burns background zoom and booking action.

### 5.3 Gallery Page ([GalleryPage.tsx](file:///c:/SavioN/Pallotti_Hill_Public_School_Website/src/pages/GalleryPage.tsx))
- **Multi-Year Archives**: Supports selection between academic years (2025-26, 2024-25, 2023-24). Inactive years (2019-2023) display "Coming Soon" badges.
- **Scroll Spy & Sticky Jump Chips**: Category filter chips stick below the navbar; clicking a chip smoothly scrolls directly to that category with dynamic navbar height compensation.
- **Masonry Layout**: Distributes images across a 3-column grid (`splitIntoColumns`) for balanced visual rhythm.
- **Category Slideshow Trigger**: Clicking "Play category slideshow" launches the lightbox in autoplay mode for that specific event.

### 5.4 Fullscreen Lightbox ([Lightbox.tsx](file:///c:/SavioN/Pallotti_Hill_Public_School_Website/src/components/Lightbox.tsx))
- Fullscreen modal supporting click-to-zoom images.
- Controls: Previous, Next, Play/Pause Slideshow, Close (Escape key).
- Auto-advancing slideshow with 3000ms delay that automatically concludes when reaching the end of the active category.

### 5.5 Institutional Assistant Chatbot ([SchoolChatbot.tsx](file:///c:/SavioN/Pallotti_Hill_Public_School_Website/src/components/SchoolChatbot.tsx))
- Floating interactive chat assistant placed at the bottom right.
- **Knowledge Engine**: Matches user questions against a keyword knowledge base:
  - Admissions criteria, grades (KG to Grade 10 CBSE), required documents.
  - School fees and payment procedures.
  - School and office timings.
  - Contact numbers, email, and Google Maps location in Mukkam.
  - CBSE curriculum and NEP-aligned pedagogical approach.
  - School bus transportation routes (GPS-enabled buses).
  - Campus infrastructure, science/computer labs, library, and sports grounds.
  - Management legacy (Malabar Marian Trust & Pallottine Fathers).
- **Interactive Action Buttons**: Directly provides telephone links (`tel:`) and Google Maps links.
- **Responsive Mobile Optimization**: Displays as a compact circular bubble on phones and full pill on larger screens.

### 5.6 Native Lazy Image Component ([LazyImage.tsx](file:///c:/SavioN/Pallotti_Hill_Public_School_Website/src/components/LazyImage.tsx))
- Uses native browser `loading="lazy"` and asynchronous image decoding (`decoding="async"`).
- Displays a golden shimmering skeleton placeholder (`shimmerPulse`) until the image is fully loaded.
- 300ms smooth opacity and scale transition upon completion.

## 6. Design System & Aesthetic Tokens

The visual identity is designed to convey prestige, warmth, and educational excellence:

### 6.1 Color Palette
- **Deep Petrol Teal (`#173c46` / `#0d242b` / `#102d35`)**: Anchor tone used for primary text, backgrounds, and headers.
- **Warm Sand Gold (`#d7b76d` / `#af8742` / `#f2d48e`)**: Accent tone for highlights, badges, borders, CTA buttons, and interactive states.
- **Linen & Alabaster (`#f6f5f0` / `#e4ebe8` / `#f1ede4`)**: Background canvas colors providing soft, natural contrast.
- **Muted Sage / Slate (`#426069` / `#5e757a` / `#cad5d2` / `#b8c9c5`)**: Secondary typography, subtle borders, and pill outlines.

### 6.2 Typography
- **Headings & Serif Emphases**: Georgia, "Times New Roman", serif (`font-serif`).
- **Body & UI Elements**: Inter, system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif.
- **Eyebrow Headers**: Uppercase, wide letter-spacing (`tracking-[0.2em]`), small font size (`text-[10px]` to `text-[11px]`).

### 6.3 CSS Animations ([index.css](file:///c:/SavioN/Pallotti_Hill_Public_School_Website/src/index.css))
- `kenBurns`: Subtle 25s continuous slow panning and scaling for hero imagery.
- `fadeSlideUp`: Smooth entrance animation with cubic-bezier timing.
- `scrollHint`: Pulsing vertical bar indicating scroll invitation.
- `shimmerPulse`: Shimmering gradient animation for image loading skeletons.
- `.gold-glow-card`: Hover card effect with radial gold glow reflection.

## 7. Data Architecture ([src/data/gallery.ts](file:///c:/SavioN/Pallotti_Hill_Public_School_Website/src/data/gallery.ts))

The gallery is data-driven, structured cleanly without hardcoded HTML repetitions:
- **`GALLERY_YEARS`**: Array defining academic years, labels, and availability status.
- **`YEAR_DATA`**: Structured dictionary holding folder names and arrays of categories:
  ```ts
  interface YearConfig {
    folder: string; // e.g. 'gallery-2025-26'
    categories: {
      name: string; // e.g. 'School Opening', 'Environment Day'
      files: string[]; // List of photo filenames within public/images/{folder}/{category}/
    }[];
  }
  ```
- **Helper Functions**:
  - `buildGalleryCategories(year)`: Generates structured categories with photo paths and index counts.
  - `getAllPhotosForYear(year)`: Flattens all category photos for continuous lightbox browsing.

## 9. Code Quality & Standards

1. **Path Aliasing**: Always import local modules using the `@/` path alias mapped to `src/` (configured in `vite.config.ts` and `tsconfig.app.json`).
2. **Asset Path Resolution**: Always use `import.meta.env.BASE_URL.replace(/\/$/, '')` when referencing static assets located in the `public/` directory to guarantee paths work both locally (`/`) and on GitHub Pages (`/pallotti/`).
3. **Lint Compliance**: Keep unused variables and imports removed so that `npm run lint` continuously exits with code 0.
4. **Type Safety**: Maintain strict TypeScript interfaces for all components and data structures.
